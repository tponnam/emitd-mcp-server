# Security

Never publish API keys, credentials, customer data, or private email content in this repository.

For safe usage:
- Create dedicated, restricted API keys.
- Use the client's secret-management facilities.
- Revoke exposed keys promptly.
- Configure sending guardrails and approval controls appropriate to your workflow.

For security issues, use Emitd's official support or security contact. A verified contact URL/email has not been supplied in this repository template yet.
