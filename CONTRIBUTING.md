# Contributing

This repository contains documentation and configuration examples for Emitd's hosted MCP service.

- Check the official Emitd MCP guide before proposing changes.
- Do not include API keys, customer data, or sensitive email content.
- Do not claim support for a tool or client unless it has been verified.
- Keep configuration examples generic and use placeholders for credentials.
- Report security concerns privately through Emitd's official support/security channel rather than publishing exploit details in an issue.

Official guide: https://docs.emitd.com/docs/guides/agents
